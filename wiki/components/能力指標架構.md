# TBCL 能力指標架構（學習表現）

## 1. 在 TBCL 與參考指引中的定位（官方標準）

在《華語文能力基準應用參考指引》中，「學習重點」由**「學習表現」**與**「學習內容」**兩個互為表裡的向度組成（來源：[[來源-2023-華語文能力基準應用參考指引]]，p.VII、10）：
- **學習表現（應知與應能，can-do）**：強調以學習者為中心，描述學習者從初學到精熟各個階段的能力表現，用以養成溝通、文化與使用華語學習的能力。
- **學習內容**：呈現達成各等級「學習表現」所需具備的漢字、詞語與語法知識（詳見 [[漢字表概覽]]、[[詞語表概覽]]、[[語法點概覽]]）。
- **教學與評量應用**：相較於較宏觀的課程目標，教師與教材編者可直接將「學習表現」或「學習內容」作為課堂上可具體操作的學習目標（例如聽力指標 `L-1-1` 或一級詞語目標）；學習評量涵蓋「學習表現」與「學習內容」，且明確規定**前者重於後者**（p.10、43）。

---

## 2. 七大面向與細項指標結構（p.11–24）

學習表現以「三等七級」展開，包含「整體表現」及 6 項分項表現（聽、說、讀、寫、譯、文化）：

| 表現面向 | 代碼 | 涵蓋級別 | 細項指標數量（1–7 級分布） | 官方備註與特色 |
| --- | :---: | :---: | --- | --- |
| 整體表現 | — | 第 1–7 級 | 每級 1 則總述（共 7 則） | 並列各級建議漢字／詞語／語法點概數 |
| 聽力表現 | `L` | 第 1–7 級 | 共 **28 條**（3 / 4 / 4 / 5 / 5 / 4 / 3） | 1–3 級強調「語速緩慢、內容清晰」；7 級納入「較快語速、不同腔調」 |
| 口說表現 | `S` | 第 1–7 級 | 共 **33 條**（3 / 3 / 6 / 7 / 6 / 4 / 4） | 涵蓋介紹、互動、演說、討論與辯論 |
| 閱讀表現 | `R` | 第 1–7 級 | 共 **23 條**（3 / 3 / 4 / 3 / 4 / 3 / 3） | 5 級起強調閱讀策略（推論、跳讀、查詢）；6–7 級納入隱含意義與言外之意 |
| 寫作表現 | `W` | 第 1–7 級 | 共 **20 條**（2 / 3 / 3 / 3 / 3 / 3 / 3） | 官方註明「寫作指書面形式的表達，**包含手寫與鍵盤打字輸入**」（p.21） |
| 翻譯表現 | `T` | **第 3–7 級** | 共 **15 條**（— / — / 3 / 3 / 3 / 3 / 3） | 考量翻譯需綜合多種技能，自第 3 級起設定；定位為許多地區常用教學與評量方式（p.11、23） |
| 文化表現 | — | **三等**（基礎／進階／精熟） | 共 **3 等描述** | 參考 Performed Culture Approach 與 ACTFL (2015)，採「螺旋式存在於各等級」之交際文化觀點（p.24） |

## 3. 各級能力演進主軸（官方摘要）

從 [[第1級能力指標|第 1 級]] 到 [[第7級能力指標|第 7 級]]，官方能力指標主要沿著**場域廣度、語言單位、認知與社會語用深度**三軸遞進：
1. **語言單位**：簡單字詞（1 級）→ 字詞、短語與短句（2 級）→ 簡單完整句與簡短段落（3 級）→ 較長段落與連貫句群（4 級）→ 流暢段落與有組織篇章（5 級）→ 書面語與結構完整篇章（6 級）→ 專業／抽象複雜文本與熟語精準運用（7 級）。
2. **活動場域**：個人生活（1 級）→ 個人與日常生活（2 級）→ 公共、學校及職場等周遭場域（3–4 級）→ 不論場域／廣泛場域的多樣主題（5–6 級）→ 複雜主題與學術／專業領域（7 級）。
3. **語用與文化層次**：高度固定化表達（基礎）→ 察覺文化差異並有意識運用文化色彩表達（進階）→ 理解幽默、反諷、嘲諷與言外之意，並依關係親疏與地位高低靈活調整表達（精熟）。

## 4. 編號格式備註

> [!warning] 原文編號示例微幅差異
> 《華語文能力基準應用參考指引》p.10 正文示例寫作 `L1-1-1`，但 p.13–23 全書正式指標表格均採用 `<技能代碼>-<級別>-<流水號>`（如 `L-1-1`、`S-4-7`、`T-3-1`）。本知識庫統一採用正式表格編號格式（來源：[[來源-2023-華語文能力基準應用參考指引]]）。
